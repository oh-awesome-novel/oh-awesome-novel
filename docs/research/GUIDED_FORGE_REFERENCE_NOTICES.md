# Guided Forge / Play / LINT reference notices

The implementation uses CicaTavern's co-creation interaction ideas and eleven Chinese prose lint categories, and StoryForge's technique cards T01/T03/T04, exact review anchors and frozen scene identity as design references. OAN storage, transport and approval integration are implemented for this repository.

References inspected:

- CicaTavern fork: https://github.com/oh-awesome-novel/CicaTavern (539d493).
- StoryForge fork: https://github.com/oh-awesome-novel/storyforge (fdfe4817).
