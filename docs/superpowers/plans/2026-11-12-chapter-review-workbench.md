# 1430 审稿工作台实施计划

1. 复用八维 Review 合同与 Novel LINT 段落锚点。冻结章稿和作者选定依据，宿主核对问题原句、依据引文/hash/范围；缺失维度标为 notChecked，无依据的文学推断明确标记。
2. `.workspace/chapter-reviews/` 保存有界 immutable 报告与单独的版本化作者裁决（处理/保留/待定）。只读生成不创建 PendingAction；过期报告仍可查看，修订前必须重验。
3. 显式修订只发送选中问题和段落，模型返回每个锚点的替换文本。宿主按原始偏移拼接，重复文本不靠搜索替换；重叠/重复范围拒绝，未选字节保持。
4. 增加 chapterReview 严格 origin，绑定报告、裁决版本、来源与选中问题/范围。通过统一 builder、prepared preview 和 materializer；Accept 再验报告/依据，并按替换长度/hash 核对候选范围之外的内容。
5. Desktop 正文章节提供审稿面板：重开报告、对照引文/依据并跳转、保存裁决、显式局部修订、普通审批。切换文件/workspace、取消与迟到响应不混用报告。
6. 分层回归覆盖只读零写入、八维缺口、重复段落/交错范围、来源漂移、裁决持久化、重启和完整报告→选择→修订→Accept 旅程。门禁后更新 task 并单独提交。
