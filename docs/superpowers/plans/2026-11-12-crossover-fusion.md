# 1500 综漫融合契约实施计划

1. 在 PLAY_MODE_SPEC 固定可选作品归属和融合契约合同。Launch v1 增加可选字段，未启用时不序列化；旧包与单作品默认行为保持不变。
2. 新增纯 Core crossover 模块，校验作品、融合方式、默认认知、规则裁定。宿主从角色来源确定作品身份；缺失归属和多作品世界规则无裁定仅警告。
3. 开局冻结契约、来源摘要与参与者边界。场景试演的初始知识按所属作品过滤，显式 Director 知识授予沿用现有记录。沉浸推演增加有当前事件依据的 learnSource 认知变更，写入现有 playKnowledge 分支快照；Restore/Retry 自动恢复。
4. 来源追踪传递作品归属，界面按作品显示实际使用的来源。作者在来源步骤标注作品，多作品时增加契约步骤；采用记录可提供待确认的归属建议；复用开局也保留契约。
5. 贯穿 Core、Backend、Client、Desktop 的严格校验与协议旅程；覆盖两作四角色隔离、显式获知/分支恢复、旧包、单作、警告及实际 SDK/HTTP/SSE 接线。运行适当门禁，更新文档并单独提交。
