# 1440 修改影响分析实施计划

1. 提供 accepted PendingAction 和显式 Git revision → 当前工作区两种只读入口。使用 structured changes / Git blob 与正文 hash，不解析 diff，不以 mtime 判断剧情变化。
2. 有界读取对象树，复用章级/卷级/全书 freshness evaluator；明确区分正式派生依赖、已登记对象引用、生成时读取记录与名称/词项命中。每条携带具体来源、范围/字段位置及 hash。
3. 报告绑定比较双方 hash、固定 Git commit、文件/证据清单，保存为可重建的内部记录；重开时重验。缺少旧版本、日志/报告被清理、超出扫描额度时明确说明覆盖不足。
4. Desktop Git 变更列表和 accepted action 提供影响入口；面板按依据分组，允许打开文件、打开审稿工作台、显式整理指定章节/卷/全书。分析不调用模型，不自动撤销状态或连锁修复。
5. 回归覆盖 accepted/外部编辑的等价派生结果、摘要递归失效、同内容 touch、明确引用/实际读取/同名误命中/无关文件、Git 不可用、重启、报告过期和大规模有界降级。完整门禁后更新 task 并提交。
