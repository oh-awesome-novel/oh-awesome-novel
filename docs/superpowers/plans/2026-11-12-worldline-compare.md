# 1490 世界线比较实施计划

1. Core 从已验证的 artifact 图读取两端快照及共同祖先；不调用恢复操作，不推进 revision。旧节点无完整快照时返回明确原因。
2. 按视角先过滤，再比较行动、状态叶路径、独有事件、计划、认知/揭示和原作节点。每组固定页大小，文本有界，不返回回合正文。
3. Backend 提供只读 GET，Client 严格核对查询绑定与有界 DTO。比较失败不写会话或新建报告。
4. 世界线增加两个节点选择器与并排差异面板。切换、命名和结果报告复用已有显式操作；切换会话、revision、视角时立即清除旧结果并隔离迟到响应。
5. Core 覆盖 sibling、祖孙、initial、旧快照、Player 隔离、1000 回合；Backend 覆盖文件 bytes 不变；Client 覆盖错误 DTO；Desktop 覆盖选择、翻页与切换旅程。运行质量门禁、更新任务状态、单独提交。
