# 0570 Workspace Global Search

> Status: Completed
> Milestone: M8 Minimal Copilot Interface

## Goal

在 workspace 工作台中增加全局搜索能力，覆盖当前小说 workspace 的 Markdown / YAML / 普通文本文件。

第一版使用 backend 按需只读扫描和 Unicode 子串匹配，不新增搜索引擎依赖。连续汉字、角色名和英文/拼音混排无需分词；现有 launcher MiniSearch 仍只负责 workspace 名称搜索。

## Implementation Notes (2026-10-01)

- Core 安全扫描服务覆盖下列白名单，拒绝 symlink、hardlink、越界/hidden 路径、无效 UTF-8 和超限文本；隐藏配置与 runtime 数据不进入结果。
- `GET /api/workspace/search?q=` 返回每文件首个命中、snippet、1-based 行号、扫描时间与内容指纹，最多 100 个结果，并明确 truncated。Client 严格校验 DTO、路径、格式和请求匹配。
- 写作工具栏搜索正文/标题/路径；键盘可操作弹窗。结果点击刷新文件树并展开祖先，右侧纯文本 FileViewer 滚动高亮命中行，不发起 Copilot 请求或自动附加 context。
- 每次查询/手动刷新都重新扫描；Accept 后触发刷新。外部编辑、删除、rename 后用刷新重新读取。工程切换关闭旧弹窗并清空文件，异步搜索/读文件回包按请求代次和 workspace 隔离。
- 每文件 2 MiB、总扫描 32 MiB、10,000 个条目、深度 24；越限明确失败，不假装扫描完整。按文件验证读取，不承诺多个文件的原子快照；并发外部编辑后可再次刷新。
- 与导出共用的目标验证：Core 22、Client 16、Backend 6、UI 10 个测试通过；Core/Client/Backend 与 Desktop UI（vue-tsc + Vite）build 通过；全量 Core 406、Client 144、Backend 148、UI 241 通过。覆盖中文混排、精确隐藏例外、链接拒绝、刷新、strict DTO、文件定位与无自动写入。

## User Experience

用户在 workspace 内可以打开全局搜索入口，输入关键词后看到匹配文件列表。点击搜索结果后：

- 左侧文件树选中对应文件。
- 右侧 FileViewer 打开对应文件。
- 如果可行，滚动到首个匹配位置并高亮匹配片段。
- 中央 Copilot 不因搜索自动发起请求或添加 context。

搜索入口可以是顶部命令、侧栏按钮或快捷键触发的弹窗。第一版不要求复杂查询语言。

## Search Scope

默认索引：

- `characters/`
- `world/`
- `chapters/`
- `state/`
- `timeline/`
- `foreshadow/`
- `summaries/`
- `outline/`
- `.oan/constitution/`
- `.oan/workflow.yaml`

默认排除：

- `.git/`
- `.workspace/`
- `.oan/sessions/`
- `node_modules/`
- 大型二进制文件。
- 非当前 workspace 的文件。

## Index Shape

每个可搜索文档至少包含：

- `path`: workspace-relative file path。
- `name`: 文件名。
- `domain`: 从路径推断的小说领域，例如 character / world / chapter / state。
- 搜索 API 只返回 snippet 与行号，不返回全文；scanner 内部读取原始文本。

第一版可以只索引纯文本内容和路径。后续可加入 frontmatter、标题、章节号、角色 id 等字段 boosting。

## Deliverables

- 按需扫描和中文子串搜索的依赖决策：首版不新增依赖。
- 有界 workspace 文本扫描与结果构建器。
- Read-only workspace file scanner for searchable text files.
- Search API or local backend endpoint.
- Search UI entry.
- Search result list with file path, domain, and snippet.
- Click result to open the plain-text file viewer.
- Empty result state.
- Index rebuild / refresh strategy.
- Tests for scope filtering and hidden directory exclusion.

## Done Criteria

- 用户可以在 workspace 内搜索当前小说工程。
- 中文短语、角色名、连续汉字与拼音/英文混排均可定位正文，并返回 snippet 与行号。
- 搜索不读取 workspace 外部路径。
- 搜索不会索引 `.git/`、`.workspace/` 或 `.oan/sessions/`。
- 搜索结果点击后打开对应文件的纯文本视图。
- 未选择文件的 workspace home 状态不会被搜索破坏，除非用户明确打开某个结果。
- 搜索不会自动触发 Copilot 或写入工具。
- Accept 后、外部编辑/删除/rename 和 workspace 切换后可刷新；首版允许手动刷新并明确过期状态。

## Constraints

- 不引入 Elasticsearch、SQLite FTS、LanceDB、向量数据库或远程搜索服务。
- MiniSearch index 是派生缓存，不是事实源。
- 不把搜索结果默认塞进 agent context。
- 不让 frontend 绕过 backend / agent 直接访问 filesystem。
- 只允许上文列出的 Constitution/workflow 隐藏控制文件例外；拒绝其它 hidden 路径、symlink 和越界文件。
- 不做 Markdown / YAML 渲染或手动编辑。
