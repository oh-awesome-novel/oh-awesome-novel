## Goal

证明正式写操作必须先形成可见 PendingAction，由人类通过 diff 明确 Accept / Reject。该审批不变量仍然有效；早期专用工具和内部 candidate layout 已由 task 0800 的 fixed sandbox、CandidateChangeSet 和 ChangeMaterializer 取代。

## Current Contract

- Model turn 只编辑 fixed in-memory projection。
- finalize 生成 normalized create/update/delete CandidateChangeSet。
- PendingAction proposal immutable，public DTO 不暴露 draft artifact path。
- Accept 后由 ChangeMaterializer 事务化写入；Reject 不写 canonical 文件。
- Git auto-commit 只发生在 durable Accept 后。
- `.workspace/change-engine/v1/` 是唯一 current approval/recovery namespace。

## Done Criteria

- 所有 AI/producer 写入都先返回 PendingAction。
- Accept 前 canonical bytes 不变。
- Accept/Reject 使用 strict action state 和 durable receipts。
- diff 可见但不作为 materialization authority。
- 旧 direct-write/专用 canonical-write tools 不再属于生产 ToolSet。

## Constraints

- Runtime 不直接写文件或 commit。
- 模型不能读写 hidden/internal paths。
- Accept 不解析 diff、不重放 command。
- 不维护 legacy compatibility API 或 old-state reader。
