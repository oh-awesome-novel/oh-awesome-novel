# 0800 Sandbox Change Engine Migration

> Status: Needs Review
> Milestone: Final Write Engine

## Related Plans

- [Migrate SemanticPatch To Sandbox Change Engine](../superpowers/plans/2026-08-12-migrate-semantic-patch-to-sandbox-change-engine.md)

## Goal

对照迁移前已落地的候选写入、PendingAction、Reference/Play adoption 与桌面审批链路，执行一次性破坏性替换：

```text
bash-tool / just-bash fixed sandbox
  -> CandidateChangeSet
  -> PendingAction
  -> human Accept
  -> transactional ChangeMaterializer
  -> Git
```

迁移只替换候选修改的生成与表达方式。Markdown/YAML/Object File Tree、Human Approval、Accept materialization 边界、crash recovery 和 Git 历史不变量保持不变。

## Scope

- 固定的内存 workspace projection、host-selected capability、PolicyFs、TrackingFs 与完整 final-document validators。
- 权威的 create/update/delete `CandidateChangeSet` 和 display-only deterministic diff。
- 严格 schema version 1 PendingAction、prepared preview、immutable draft、terminal record 与 decision receipt。
- operation-aware transactional materialization、rollback/recovery、Git auto-commit 与 quick-commit recovery。
- Runtime turn finalizer、Agent shared session、bounded/sanitized bash audit、abort/dispose 生命周期。
- Reference publication/adoption、Play adoption 与其它正式 producer 统一到 ChangeSet/PendingAction。
- Backend、Client 与 Desktop review DTO/UI 的 create/update/delete 协议。
- 原子生产切换后删除全部 SemanticPatch、旧 write-intent、restricted canonical write 与旧 fixture。
- 一次性 disposable internal-state reset、稳定文档重写、legacy-term gate 与全量 build/package smoke。

## Done Criteria

- 完整链路是 `bash-tool/just-bash -> CandidateChangeSet -> PendingAction -> Accept -> Git`。
- Accept 前任意模型命令都不能改变 canonical bytes；Accept 不重放命令或解析 diff。
- create/update/delete 多文件事务可 rollback，并能按 durable commit point crash-recover。
- 每个 write session 的 capability 由可信 host 选择；所有 writable family 有最终文档 validator。
- 所有正式 producer、Runtime、Backend、Client 和 Desktop 只使用新协议。
- 生产代码和测试 fixture 不再包含 legacy write engine API。
- 旧内部记录明确报 unsupported，开发 workspace reset 不改变 canonical 文件或 Git 历史。
- 计划中的 tools/runtime/agent/core/backend/client/desktop、build、package、Electron smoke、文档与 diff 门禁全部通过。

## Constraints

- 不暴露 host shell、host filesystem、network、Python、JavaScript、trusted custom command 或 `.git`。
- 不实现 feature flag、双引擎、dual-run、compatibility reader、旧记录 migrator 或 runtime rollback path。
- diff、command log 与 mutation log 都不是 Accept authority。
- 不把确定性 producer 强制翻译成 shell 字符串。
- 不删除或改写 canonical novel 文件、workspace 配置或 Git 历史。
- 测试继续放在根目录 `__test__/` 对应 workspace。
