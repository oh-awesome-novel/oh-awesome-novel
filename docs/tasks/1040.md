> Status: Completed

## Related Plans

## Goal

为长任务和需要续跑的 agent run 建立轻量、disposable session artifact，而不是引入复杂 run-ledger 数据库。

## Current Deliverables

- `.workspace/sessions/<session-id>/` author-facing artifact layout
- strict files:
  - `run.yaml`
  - `context-package.yaml`
  - `outputs.yaml`
  - `proposed-changes.yaml`
  - `unresolved.md`
- proposed changes only contain public action identity/status/structured change summaries
- resume boundary helper and author report formatter
- safe path/id guards and manual-edit detection

## Done Criteria

- 长任务记录 selected sources、outputs、public proposed change summaries、时间与未决问题。
- artifacts 不保存内部 draft path、candidate bytes、raw bash args 或 hidden reasoning。
- 用户手改 canonical 文件后，resume 明确提示沿用、继续或放弃旧草稿。
- 最终报告面向作者，不输出原始 JSON、traceback 或长命令日志。

## Constraints

- 普通 chat turn 不强制写完整 artifact。
- session artifact 不替代 Git 历史或 canonical truth。
- `.workspace/` 与 `.oan/sessions/` 可在 one-time internal-state reset 中整体丢弃。
