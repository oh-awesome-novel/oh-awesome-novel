## Goal

规划并实现独立 Play Mode / Roleplay Sandbox，并接入 Tavern-compatible Character Card 导入能力。

Play Mode 既服务沉浸式体验，也能把 Play observation 转成写作草稿或参考，但默认不改 canonical truth。

## Deliverables

- Play Mode product spec update
- Play session filesystem spec：
  - transcript
  - play-local state
  - activated sources
  - observations
  - adoption candidates
- single world referee + multi-character voice/state modules design
- Tavern-compatible card parser implementation plan
- OAN character card interaction hints / lorebook integration
- UI route / panel plan
- tests 覆盖 import normalization、prompt injection guard、Play adoption PendingAction

## Done Criteria

- Play session 与 Writing Mode 并列，不只是 `/写下一章` 的隐藏 rehearsal。
- Play 读取角色卡、interaction hints、lorebook、世界规则、当前状态和起点。
- Play 结果默认只进入 Play session。
- 用户确认后，Play observation 才能转成章节草稿、状态、时间线或伏笔 PendingAction。
- Tavern-compatible import 不复制 SillyTavern AGPL 代码，不声称官方兼容。

## Constraints

- 不引入默认重型多 agent runtime。
- 不自动把 imported character prompt 覆盖 constitution / world / state。
- 不从分享站点自动抓取角色卡。

## Import Journey (2026-10-07)

Play 产品面与 adoption 已由 1090、1120、1130–1190 交付。本轮按用户请求补齐 Tavern 的本地文件 UI/API、候选正文与 create/merge/play-only/activation 旅程。

- Play 顶栏提供 Import character：本地 JSON/PNG → 模式与角色 ID → 预览/冲突说明 → 创建审批或明确创建 Play 会话。文件/映射变化使旧预览失效。
- JSON 上限 1 MiB、PNG 10 MiB、PNG metadata/解压 2 MiB、chunk 4096、lorebook 500 条/256 KiB；结构另有限制深度/节点数。V3 `ccv3` 与 V2 `chara` 均按 UTF-8/base64 解码，重复 metadata、损坏/过大输入拒绝。
- `tavern-import` deterministic producer 为七个明确 character targets 生成正文。create 拒绝已有目录；merge 保留已有 meta/summary/personality，列出冲突，并去重追加 interaction/lore。完整七文件 read set、源 hash、mapping hash、repository baseline 与预览 fingerprint 在 promotion/Accept 重验。
- create/merge 使用统一 immutable prepared preview → PendingAction → Accept；Reject 不改正式文件。来源记录保留 hash/creator/字段清单和信任说明，不自动下载外链资源。
- Play-only 预览仅存宿主有界内存，15 分钟/重启后需重新预览；明确确认后通过 create-only staged writer 保存新 session。卡片内容是 Play-local metadata，不写 `characters/`；重开后仍能使用。
- Play 提示词只加载 bounded hints 和匹配的 enabled lore，最多 16 条；Play-only 不主动注入 system/post-history/depth/creator notes。正式角色的 interaction/lorebook 通过 Guided Start 显式选择后也保持 `interactionHint`，不会覆盖 Constitution/canonical facts。
