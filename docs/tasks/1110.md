# 1110 ContextPackage Evidence And Agent Usage Governance

> Status: Planned
> Milestone: Agent Observability And Context Governance

## Related Plans

- [ContextPackage Evidence And Agent Usage Governance Plan](../AGENT_USAGE_AND_CONTEXT_STATS_PLAN.md)

## Goal

为 agent copilot 增加可审计的 ContextPackage 来源证据、message/context token estimate、provider egress 摘要和 AI SDK actual usage 统计。

这项任务的目的不是做复杂 observability 平台，而是让 OAN 能回答：

- 本轮 agent 实际送入了多少上下文。
- 哪些 context source 占用了主要 token budget。
- 哪些 source 被选择、压缩、省略或排除，来源版本和 payload hash 是什么。
- protected source 是否发生可见 overflow，而不是被静默截断。
- 哪些 source 的派生内容被发送到哪个 provider / model / endpoint origin。
- provider 返回了多少 input / output / total tokens。
- provider 没有返回 usage 时，系统仍能提供清晰的 estimated stats。

## Current State

当前已有基础：

- `ContextPackage` 记录 selected / omitted / reason / budgetLayer。
- `ContextPackage` 和 session artifact 已有 trace、workspace-relative path 与部分 input source hash 基础。
- runtime context builder 会把上下文转成 model-visible messages。
- AI SDK `streamText` 已提供 `usage`、`totalUsage`、`onFinish.totalUsage` 和 `onStepFinish.usage`。
- provider model config 已支持 `contextWindow` 和 `maxOutputTokens`。

当前缺口：

- OAN 没有 message-level estimated token stats。
- OAN 没有 context-level estimated token stats。
- OAN 没有为 selected source 记录 source hash、exact payload hash、model-visible chars / tokens 和 selection outcome。
- `protected` / `compressible` 仍主要是标签，没有统一 budget unknown / deterministic omission / protected overflow 语义。
- OAN 没有把 AI SDK `totalUsage` 接入 runtime result。
- OAN 没有 session-level usage artifact。
- OAN 没有安全的 provider egress summary。
- UI 没有展示 estimated / actual token usage。

## Deliverables

- Context source evidence：path、revision/hash、payload hash、selection outcome、chars 和 estimated tokens。
- Budget resolution、deterministic compressible omission 和 pre-provider protected overflow。
- message / context estimated token stats。
- AI SDK `streamText.totalUsage` capture。
- Provider/model/endpoint origin/source refs egress summary，不包含 secret 或 raw content。
- runtime `model_request_stats` event。
- runtime `usage_stats` event。
- turn-level aggregated usage summary。
- session artifact：`.workspace/sessions/<session-id>/usage-stats.jsonl`。
- Backend/client bounded governance history API 与 strict parser。
- UI Context & Usage inspector，明确区分 selected/model-visible、estimated/actual、partial/unavailable。
- tests 覆盖 provider missing usage fallback。

## Done Criteria

- 每个 writing-related standard agent run 的 file-backed source 尽可能记录 workspace-relative path、sourceHash 和 payloadHash。
- selected / compressed / omitted / excluded 有独立 outcome 和 reason。
- 已知预算下 protected source 不会被静默截断；overflow 在 provider 调用前结构化失败。
- 预算未知时继续记录 estimate，但不使用臆造阈值阻断请求。
- 每次 model step 都能记录 estimated input stats。
- provider 返回 usage 时，step stats 包含 actual usage。
- provider 不返回 usage 时，actual usage 保持 unavailable，不伪造为 0。
- turn finish result 包含 aggregated usage summary。
- session artifact 可恢复查看 usage stats。
- UI 明确展示 estimated / actual、partial / unavailable 和 provider egress 的区别。
- context package summary、summaries、state、timeline、foreshadow 等 context item 能按 kind 汇总 estimated tokens。
- artifact/API/UI 不包含 raw prompt、source content、API key、header value、URL path/query 或 workspace 绝对路径。
- 测试覆盖 core evidence/stats、budget、runtime event、agent AI SDK usage capture、artifact、backend/client/UI stream data。

## Constraints

- 不引入 provider-specific tokenizer 或重型 tokenizer dependency。
- 不写入小说 truth files。
- 不改变现有 prompt assembly 顺序。
- 不阻塞 provider missing usage 的模型调用。
- 不把 estimated token 当作真实计费数据。
- 不引入重型 agent runtime 或 observability 平台。
- 不保存 raw prompt、completion、provider usage raw payload、secret 或隐藏 reasoning。
- 不为普通聊天增加每轮阻塞式 execution consent。
- V1 只要求 standard Novel Agent 纵向闭环；reference / Play 专用 pipeline 后续按需复用 helper。

## Recommended Implementation Order

1. 在 `packages/core` 增加 evidence、estimator、budget 和 normalized usage helper。
2. 在 agent 组装层补 source/payload identity、provider egress 和 protected overflow。
3. 扩展 runtime model response、turn result、`model_request_stats` 和 `usage_stats` event。
4. 在 agent AI SDK adapter 中读取 `streamText.totalUsage` / `finishReason`。
5. 将 step / turn usage 写入 session artifact。
6. 增加 backend/client bounded history API 与 strict parser。
7. 将 context evidence / usage 转成 UI stream data chunk。
8. 在桌面 UI 中实现轻量 Context & Usage inspector。
9. 补齐 core / runtime / agent / backend / client / desktop-ui 测试。
