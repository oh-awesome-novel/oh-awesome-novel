# 1205 Reference Quality Gate Warning Degradation

> Status: Completed
> Milestone: Writing Profile W2a

- [Writing Mode Commercial And Fanfiction Upgrade Plan](../WRITING_MODE_COMMERCIAL_AND_FANFICTION_UPGRADE_PLAN.md)
- [Reference Work Deep Deconstruction Upgrade Plan](../REFERENCE_WORK_DEEP_DECONSTRUCTION_UPGRADE_PLAN.md)

## Goal

把现有 Technique Track 的内容质量判断从发布阻断降级为用户可见 warning，
同时保留所有结构完整性检查及其 fail-closed 行为。只有可读取、可追踪、可恢复
的产物才能进入 Publish Review；作者可以自行决定是否接受内容层提示。

## Scope

- `ReferenceDeconstructionQualityStatus` 增加 `warned`。
- Quick Preview 与 full quality gate 的 exact-overlap 诊断改为 non-blocking
  warning；distilled category 缺失和既有 uncertainty 同样归入 warning。
- analysis quality report、run state、manifest、progress、readiness、Client
  strict guard 与 Desktop 发布判断接受 `warned`。
- manifest 持久化 warning 数量与去重诊断码。
- PendingAction description 和 Publish Review 显示 warning 数量。
- Core、Backend、Client 与 Desktop 分层测试覆盖 warning 可发布和结构故障仍阻断。

## Out Of Scope

- Story Material typed analysis track、`materials/*`、per-track work plan /
  stage / manifest output kind。
- `coveragePercent === 100` 的松绑、纯 material context index 或部分发布。
- warning suppression、material 专属阈值、启发式相似度评分或法律判断。
- 把 quality diagnostics 回灌给模型。
- Play Mode、Profile reminder 或 D5 评分 / token budget 改动。

## Done Criteria

- 无诊断为 `passed`；只有 non-blocking 内容诊断为 `warned`；任一结构完整性
  blocking 诊断为 `failed`。
- `warned` run 可以进入 `reviewReady`、创建 PendingAction、完成 publish，
  并保持 `contextEligible`。
- exact-overlap 与 missing-category 检查仍运行且保留原诊断码，只修改
  `severity` / `blocking`。
- Preview `coverage.incomplete`、copy-risk scan overflow、diagnostics overflow、
  invalid plan / attempt / hash / evidence / output 等结构错误继续阻断。
- completed manifest 记录 warning 数量与诊断码，且 strict parser 拒绝不一致数据。
- Publish Review 与 PendingAction description 均能在 Accept 前说明 warning 数量。
- 既有 0900 回归更新并通过；不提前落地 1210 范围。

## Constraints

- 所有检查继续执行，不因降级删除诊断。
- W2a 仍要求 Technique Track coverage 为 100%。
- Published reference 只有 accepted、current 且 `passed | warned` 时才可被 D5
  selector 使用；persisted blocking diagnostics 仍强制 `qualityFailed`。
- 测试继续放在根目录 `__test__/` 对应 workspace。

## Implementation Notes

### 2026-07-31

- Core 的 manifest / analysis report / run summary 四态均增加 `warned`。最终
  状态由完整 diagnostics 决定：无诊断为 `passed`，只有 non-blocking
  diagnostics 为 `warned`，任一 blocking diagnostic 为 `failed`。
- Quick Preview 与 full-run exact-overlap、distilled missing-category 保留原
  检查和诊断码，仅降为 `severity: warning` / `blocking: false`；Preview
  coverage、plan / attempt / output / hash / evidence closure、diagnostic overflow
  与 copy-risk scan overflow 继续 fail closed。
- `reviewReady`、publication candidate、completed manifest、progress projection、
  readiness inspection 与 Client strict guard 接受 `warned`。旧 manifest 缺少
  必填 `warningSummary` 时明确进入 rebuild，而不是静默猜测。
- completed manifest 保存 non-blocking diagnostic 总数和排序去重后的 code；
  readiness 会把该摘要与 `diagnostics.yaml` 交叉校验。`warned` bundle Accept 后
  保持 `contextEligible: true`。
- Backend 的 reference publish PendingAction description 带 warning 数量。
  Desktop 新增 `ReferenceQualityWarnings`，按 code 分组展示 stage / chapter /
  unit / pointer / evidence 与操作建议；带提示时需先展开列表，之后才可创建
  PendingAction，Core 没有增加新的 hard gate。
- 分层回归通过：Core 39 files / 312 tests、Runtime 1 / 11、Agent 7 / 57、
  Backend 7 / 102、Client 8 / 111、Desktop 44 / 209，共 106 files /
  802 tests；Desktop production build 与真实 Electron renderer smoke 同步通过。
- W2b 的 Story Material track、per-track work plan / stage、`materials` output
  kind、纯 material context index 与部分发布均未提前实现。
