## Goal

在现有 reference deconstruction controller、run storage、source window、恢复与
PendingAction 发布链路内增加独立的 Story Material typed analysis track。商业写作
继续只产出抽象 techniques；同人二创只产出带 evidence 的具体故事材料；自定义
Profile 可以在同一个 run 中执行两条 track。

## Scope

- run 固化最小 `profileId + outputs`，resume 不读取新的 Profile 配置改写原 run。
- work plan、terminal unit、stage、quality summary 与 manifest 按
  `technique | storyMaterial` track 化。
- Material Coverage Preview、Chapter Findings、Aggregate、Projection 的独立
  typed schema、prompt、normalizer、evidence closure 与 diagnostics。
- `world | characters | relationships | outline | timeline` YAML formatter。
- `materials` manifest / publication inventory、deterministic ChangeSet kind 与路径约束。
- material-only 空 context index、`contextEligible: false` 与 completed bundle。
- selected projection 原子部分发布，保留未选择 projection 及其 provenance；stale
  按 projection/source checksum 独立表达。
- Client strict guards 与 Desktop Preview / Publish Review / References 分组展示。
- Core、Agent、Tools、Backend、Client、Desktop 分层测试。

## Out Of Scope

- W3 的 selected material adoption、workspace CandidateChangeSet 或目标文件写入。
- 原作 binding、canon checkpoint、多 source merge、自动同步或 material selector。
- reference 原文或未采用 materials 进入正式 Writing。
- 第二套 controller、后台任务、多 Agent runtime 或数据库。
- 新法律判断、warning suppression 或 material 专属相似度阈值。

## Done Criteria

- commercial / fanfiction / custom both 分别构造合法的单轨 / 双轨 work plan；两轨
  共享 source window pointer identity，但使用独立模型合同和 output closure。
- material-only run 从 Preview 到 `completed` / accepted publish 全链路可用，不生成
  distilled entries，空 context index 明确记录 Technique Track 未运行。
- custom both 的任一 track 未完成或结构失败时，不会伪装对应 projection 已完成。
- Story Material 每条 entry 都包含稳定 id、`fact | interpretation | uncertain`、
  confidence，以及 evidence 或明确 uncertainty。
- `materials/*` 可进入现有多文件 PendingAction，非法扩展名和越界路径仍 fail closed。
- 部分发布不删除、重写或错误标 stale 未选择且仍 current 的 projection。
- Technique prompt / schema / projection 抽象边界保持不变；正式 Writing 边界不变。
- 未知或旧的单例 terminal schema 明确报错，不静默迁移。
- 相关分层测试、build、renderer smoke 与 `git diff --check` 通过。

## Constraints

- import、chunk planner、run lock、resume、source drift 和 publish framework 只能扩展，
  不得复制。
- AI 产物在 Accept 前只存在 `.workspace/change-engine/v1` immutable candidate / PendingAction 中。
- exact-overlap 继续检测并作为 warning 展示，不新增 material 特例阈值。
- 测试继续放在根目录 `__test__/` 对应 workspace。

## Historical Implementation Notes

### 2026-07-31

- deconstruction run 现会固化 `profileId + outputs`，并从 outputs 派生
  `technique | storyMaterial` track。resume、retry 与 restart 只读取原 run
  snapshot，不会因当前 Profile 后续变化而改写执行范围。
- work plan、stage transport、terminal units、quality reports 与 completed
  manifest 已升级为 v2 per-track 合同。Technique-only、material-only 与 custom
  both 使用同一个 controller、chunk planner、run lock、source window 和 source
  drift 检查；两条 track 共享 source pointer identity，但分别生成 typed chapter /
  aggregate / projection 单元。旧的单例 terminal schema 会被 strict parser 明确拒绝。
- Core 新增独立 Story Material Coverage Preview、Chapter Findings、Aggregate、
  Projection 与 quality schema。每条材料携带稳定 id、
  `fact | interpretation | uncertain`、confidence 和 evidence / uncertainty closure；
  `world | characters | relationships | outline | timeline` 分别格式化为严格 YAML。
- Agent 为四个 material 阶段使用独立 AI SDK typed-output prompt 和 schema，不注册
  tools，也不消费 Technique findings。exact-overlap 检查继续执行并作为 warning
  保留定位信息；plan、attempt、hash、predecessor、evidence 与 output closure 错误
  继续 fail closed。
- 发布候选和 manifest 现支持 `materials` kind。Apply Engine 只允许五个确定的
  `materials/*.yaml` 路径进入现有多文件 PendingAction；隐藏路径、目录穿越、
  symlink、非法扩展名和未声明 kind 仍被拒绝，Accept 前不写真实 reference bundle。
- 部分发布按 selected projection 原子替换。每个 output 持久化 `sourceRunId`、
  source checksum 与 stale 状态；同 source 下未选择的 current projection 保持原
  provenance，不会被删除或误标 stale。source 变化时才按 projection 独立失效。
- material-only completed bundle 使用空的 Technique context index，显式记录
  `techniqueTrackRan: false`、`contextEligible: false` 和
  `techniqueTrackNotPublished`，同时仍可作为合法 reference bundle 完成发布。
  同 source 的后续 material-only 发布可以保留既有 Technique context。
- Client strict guards 已覆盖 v2 run / preview / per-track quality / publication
  inventory；Desktop 新增 Story Material Coverage Preview，并在 full progress、
  Publish Review 与 References 中把“具体事实材料”和 Technique observations 分区
  展示。W3 的 selected material adoption、workspace patch 与 Accept 后 truth-file
  写入没有提前实现。
- 验证通过：Core 40 files / 328 tests（其中 reference 定向 8 / 74、Story
  Material 10 tests）；Agent 8 / 61；Tools 7 / 83；Backend 7 / 107（其中
  localhost reference integration 16 tests 在授权环境运行）；Client 8 / 116；
  Desktop UI 44 / 215。Core、Agent、Tools、Backend、Client builds、Desktop
  production build、真实 Electron renderer smoke 与 `git diff --check` 同步通过。
