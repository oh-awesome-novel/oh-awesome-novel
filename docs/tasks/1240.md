> Updated: 2026-10-01

## Goal

用户要求先提交评审修正，再升级 AI SDK。基线为 `17ab51b`；升级 npm 当前稳定 `ai@7.0.126`、`@ai-sdk/openai@4.0.83` 和 `@ai-sdk/vue@4.0.126`，同步全部 workspace 声明与 lockfile。

## Constraints

- 保留 Node 24、ESM 包输出、现有 Aider-style Runtime、固定内存 projection、CandidateChangeSet/PendingAction/Human Approval。
- 不引入 SDK Agent 替代现有 loop，不新增 telemetry、Extension 或其它产品能力。
- 保留 pinned bash-tool / just-bash，先验证其现有 AI SDK 7 peer 兼容。
- 不修改独立用户技能配置；已提交业务基线足以回退此次迁移。

## Done Criteria

- npm 依赖解析不保留无意的 SDK 6 运行副本或 invalid peer。
- SDK prompt、stream、tool execution 和末步结果消费按目标版本契约迁移。
- Vue chat/transport 保持响应性、暂停/恢复、流式事件、tool/PendingAction 可见性。
- 相关构建、桌面类型检查、Agent/Runtime/Tools/Backend/Client/UI 回归通过。
- 包装后 Node/Electron 使用的 ESM 入口可载入，无真实 provider key 的测试不冒称联网验收。
- Typecheck 以迁移前诊断为基线，新增 SDK 相关错误必须修复；不把既有错误掩盖为通过。

## Implementation Notes

- 所有 ai/OpenAI/Vue workspace 声明与 lockfile 已统一；`npm ls` 确认只有 `ai@7.0.126`，无 invalid peer。`bash-tool@1.3.18`、`just-bash@3.2.0` 保持固定版本并通过真实 dependency smoke。
- 标准 Agent、Play 和 Reference 使用 SDK `instructions`；完整事件流使用 `stream`，标准 adapter 通过 `finalStep.toolCalls` 保持末步语义。SDK 不执行 OAN tools，执行权仍在现有 Runtime。
- adapter 显式处理 error/abort 与 error finishReason，部分输出不能被误判为成功；length 仍可返回已生成文本。未知 UI stream 异常使用通用错误，既有 Runtime public error event 保留。
- Runtime 按 SDK 7 `ToolExecutionOptions` 传入 toolCallId、合法消息历史、context 和 abortSignal。system instructions 不进入 tool messages；取消后的剩余工具不执行，并补齐结果以保持消息配对。没有新增 raw bash 审计内容。
- 两个 Vue chat composable 使用 `useChat`，每个会话保持独立响应式实例与 scope，卸载时取消请求并清理。真实 SDK 流测试覆盖 UTF-8 分块、text/tool/PendingAction、stop/继续、切换、卸载和失败后的输入/附件保留。
- Reference 结构化输出保留原错误分类；依照 v7 默认 toolChoice / eager output 行为调整真实 mock 测试，没有降低原 schema/evidence 合同。
- 更新 `1110` 的 usage 接线文档：SDK 7 的 usage 聚合所有 SDK steps，finalStep.usage 表示末步，避免与 deprecated totalUsage 重复累计。此次不增加 usage 产品功能。
