# 1250 Illustrated User Documentation

> Status: Completed
> Milestone: M12 Polish, Tests, Import / Export

## Goal

使用精确版本 `vitepress@2.0.0-alpha.20` 提供中文使用文档，并配上当前应用的真实界面截图。

## Scope

- 在根目录 `wiki` 建立 VitePress 站点，提供开发、构建与预览命令。
- 按已实现界面编写启动、模型配置、工作区、写作与审批、参考资料、Play、Git 和常见问题指南。
- 使用隔离演示数据运行现有应用并截图，记录截图更新方法。
- 从仓库首页和开发文档索引链接到使用文档。

## Constraints

- 原有 `docs/` 稳定设计文档保持其架构事实地位。
- 不改变产品功能，不将计划中或未接线功能写成已交付操作。
- 截图不能包含真实凭据、私人小说或用户机器的配置数据。
- 不绕过产品的 PendingAction / Human Approval 写入边界。

## Done Criteria

- lockfile 中 VitePress 精确锁定为 `2.0.0-alpha.20`。
- 中文导航、搜索与主题切换可用；页面内部链接和图片通过构建与浏览器检查。
- 主要操作指南有清晰步骤；应用可直接运行时补对应截图。按用户 2026-10-01 的补充，其他对话正在修改项目时优先交付文字，不能运行的界面允许暂缓截图并注明。
- 文档构建通过，并检查桌面与窄屏显示。
