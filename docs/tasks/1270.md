## Scope

Deliver the minimal readable Markdown/TXT export from 0700 and review B03. Export only saved `chapters/NNNN/NNNN.md` bodies, excluding `0000.md` summaries and YAML frontmatter. Order by volume then chapter number. Export does not modify any canonical file and accepts no backend destination/overwrite path.

## Done Criteria

- An author explicitly selects Markdown or TXT download from the writing toolbar.
- The download has a timestamped filename; UI explains browser save-location/overwrite behavior and exclusions.
- Safe read scanner rejects symlinks, hardlinks, unsafe paths, binary/oversized files and malformed frontmatter.
- Backend → strict client → UI contract and read-only tests pass.
- Import, upper-level summaries and Extension development remain deferred/separate.

## Implementation Notes

Core/Client/Backend and Desktop UI (vue-tsc + Vite) builds and 54 dedicated tests across Core (22), Client (16), Backend (6), and UI (10) pass. Markdown retains prose formatting and uses separators between chapters. TXT removes heading prefixes but preserves inline Markdown syntax. Limits and non-atomic multi-file read behavior are documented in the related plan.
