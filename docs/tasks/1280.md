## Goal

通过 GitHub Actions 构建未配置证书签名的 Electron 安装包，并在版本标签发布时上传 GitHub Release。

## Scope

- macOS arm64/x64 ZIP、Windows x64 Squirrel 安装器、Linux x64 DEB/RPM。
- 推送 `v` 开头的 SemVer 标签自动发布；手动运行支持只构建或发布已有标签。
- 安装、构建、packaged main smoke、产物上传与 Release 发布统一接入现有 Forge 和 Nx 构建链。
- 修复干净 runner 上的 make 前置步骤及安装器元数据。
- 修复平台构建检查暴露的内存覆盖写入权限保留问题，避免 Windows 的正常内容编辑被误报为 chmod。

## Constraints

- 不配置开发者证书、Windows Authenticode 签名或 macOS notarization。
- 版本号由标签写入 CI 临时 checkout，不改写或提交 canonical 源码版本。
- 全部目标成功后才公开 Release；上传失败保留 draft，已发布版本不得自动覆盖。
- 手动无标签运行只保存 Actions artifacts，不创建版本标签或公开 Release。
- 不修改小说对象文件、模型配置或产品审批流程。

## Done Criteria

- Workflow YAML 与命令通过检查。
- 干净构建可从源码生成应用包和安装器，不依赖已存在的 `out/`。
- CI packaged smoke 验证 sandbox 的内存候选产生与 canonical bytes 不变。
- 产物附带 SHA256SUMS，并记录触发、版本、下载与签名边界。
