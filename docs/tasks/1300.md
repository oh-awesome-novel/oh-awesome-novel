## Goal

作者能将自有旧 Markdown 稿件预览、拆章并映射为 OAN 章节，通过现有 PendingAction 审批正式导入。

## Scope And Constraints

- 输入为有界 UTF-8 Markdown 文本/文件；不接收宿主文件路径，不调用模型，不与外部 Reference 或已有 OAN workspace 导入混同。
- 确定性拆章、可调整卷章映射、可见原文/目标预览；无标题文本可作为单章。正文不得静默丢弃，无法可靠处理的输入明确报错。
- 初版只创建新章节；重复映射或既有目标冲突必须重映射，不隐式覆盖或合并作者正文。
- 预览绑定原稿、映射与 workspace/repository/target 基线；更改输入或映射后重新预览。用户确认后创建 immutable CandidateChangeSet / PendingAction。
- Accept 前不写正文；Accept / Reject / stale / Git 行为全部复用统一 materializer。公共 DTO 不暴露候选全文或内部 draft 路径。
- 单次批量受现有 ChangeSet/validator/文件大小限制，错误清楚可操作；大稿可分批。

## Done Criteria

- 从 Writing 可进入旧稿导入，完成文件/文本输入、卷章映射、冲突处理、预览、创建候选、审阅接受或拒绝。
- 覆盖中文章标题、Markdown 标题、无标题、正文保留、非法/重复映射、大小限制、目标冲突和预览后漂移。
- 使用临时文件系统与真实 Git 验证 API 至 Accept/Reject；Accept 前 canonical bytes 不变。
- Client 严格 DTO，UI 在 workspace 切换和迟到响应后不显示/提交旧工程候选。
- 更新对应 task、稳定文档与作者指南；卷/全局摘要仍单独验收。

## Implementation Notes

- Core `prepareManuscriptImport` 支持 Markdown 标题、中文章标题、无标题单章、fenced code 与前置 frontmatter；原稿切片按顺序逐字保留，包括 BOM / CRLF / 前言 / 原标题 / 末尾空白。额外添加规范 frontmatter 和映射标题；卷标题不自动分卷，预览明确提示手动映射。
- 上传文件仅支持 UTF-8 `.md`，源稿最多 512 KiB / 64 章；卷章号 1–9999。重复或既有目标必须重映射，不隐式覆盖。
- Tools 新增 deterministic producer 与 strict `manuscriptImport` origin（previewId / sourceHash / mappingHash）；prepared preview、promotion 和 materializer 独立检查 exact create-only 目标及原预览绑定。公共数据只返回来源/映射元数据、hash 与 display-only diff。
- Backend 提供 `/api/workspace/manuscript/import/preview` 和 `/previews/:id/pending-action`；请求有界，root 由 host 决定，`expectedWorkspaceRoot` 只作工作区切换检查，不作为路径 authority。Propose 仅接受预览 ID/fingerprint，支持重启与同预览幂等恢复。
- Writing 工具栏接入输入、映射、冲突/diff、创建候选、既有 Approval；无需 provider。文件读取使用 fatal UTF-8 decoder，输入变化、关闭窗口、切换工作区使迟到响应失效。
- 创建候选响应丢失时，UI 只读查询已知 ID 并核对来源/目标；无法确认时提示先查看待审批列表，不自动重复提案。Shell 的待审批、健康与状态刷新同时隔离工作区切换。
