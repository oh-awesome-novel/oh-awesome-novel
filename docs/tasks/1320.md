## Goal

为小说IDE设计统一图标，并用于Electron应用本体、安装包、开发窗口、启动页及浏览器页签。

## Scope

- 墨蓝底、暖白展开书页、负形笔尖与金色书签的单一图标，透明边缘与小尺寸可读性。
- 保留生成母版和可重复的PNG/ICO/ICNS尺寸转换；记录设计意图、完整生成提示词与资源位置。
- Forge packager、Squirrel、DEB/RPM、BrowserWindow与macOS开发Dock接线，确保production资源不依赖源码目录。
- 启动页与favicon统一图标，不改变应用功能、主题或导航。

## Done Criteria

- 真实PNG/多尺寸ICO/ICNS文件有效，保留透明度；缩小后图案清晰。
- Desktop与Vue类型/构建检查通过，macOS打包资源实际包含自定义图标。
- 打包写作smoke通过；其他平台未本机执行的范围明确记录。
- 不修改小说工作区、provider或审批语义。

## Implementation Notes

- 内置imagegen生成“展开的故事”图标：书页、负形笔尖、金色书签，墨蓝底和真实alpha透明边缘。1254px原始母版保存在 `apps/desktop/assets/icon-source.png`，完整prompt与设计说明见该目录README。
- `npm run icons:build` 使用macOS原生sips/iconutil，从母版生成1024/512px PNG、16–1024px ICNS、7帧16–256px ICO、256px启动页图片和32px favicon。Windows/Linux构建使用已管理的产物，不运行转换工具。
- Forge packager接ICNS/ICO，Squirrel Setup接ICO，DEB/RPM接512px PNG；extraResource将图标复制进`resources/icons`。BrowserWindow区分开发/发行路径，macOS开发Dock使用相同图案。
- 启动页和favicon已替换旧占位图标；彩色图标在深色主题下不反相。没有改动布局、provider或写作审批链。
