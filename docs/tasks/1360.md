## Remaining review and limitations

- Live-model literary quality and provider cache billing were not measured. No image-generation/TTS calls are introduced.
- Prefix byte stability works with OpenAI-compatible and Anthropic adapters. Anthropic system/stable-reply cache points are verified using mocked HTTP; actual cache hits, latency and billing need live credentials.
- Archive continuation preserves the immutable historical graph to keep resource/event references valid; only model-visible history is compacted. Current character/scene facts require exact field-bound current-state evidence; unbound fields are marked 未记录. Historical chronicle and current unresolved threads retain literal history checks, and an occurrence that is the tail of a negated clause cannot vouch for a quote; style remains interpretive and author-reviewed.
- VN v4 supports interactive streaming; v5 presents committed replay. Inline markup is balanced but rendered as safe text. Local scenery follows [the documented convention](../PLAY_LOCAL_SCENERY.md).
- Forge drafts use bounded YAML-compatible JSON and exclusive filesystem locks. A process crash while holding a draft lock fails closed and requires operator lock recovery after confirming the process is gone. Canonical transaction recovery remains the existing materializer path.
- LINT flags are suggestions. Empty model correction lists can leave flags; semantic fact preservation still requires author approval. Structural quote/span/hash isolation is enforced.
- The task stays Needs Review for live-provider quality/cache validation. Local native Electron could not start; exact-commit cross-platform packaged smoke results are recorded separately in the PR and do not replace live-provider validation.

### PR review follow-up

- Stage snapshots are bounded when created (first-line scene label, oversized beats split, excess beats packed) and validated before the turn commits, so a valid referee reply cannot leave an unreadable session.
- Play creation only fails on broken roster profiles the session uses; extra or ambiguous scenery is skipped; oversized permanent context files are truncated to the 64 KiB/256 KiB freeze budget with a note instead of rejecting launch. Link and hard-link rejection is unchanged.
- `novel.lintScan` and `novel.deAi` are in the Copilot skill allowlist, with an agent test through runtime skill filtering.
- Archive continuations are sent once as a prior message; VN choices only come from a trailing numbered block.

### Plan gap follow-up (2026-10-24)

A review against both plans and the references found deviations from the plans' goals; these are now addressed:

- P1: turn-invariant referee rules and output protocol live in the frozen prefix (marked `每轮回复都要遵守`); the tail carries separate `<世界设定>`, `<当前状态>`, `<本轮回合要求>` and `<玩家输入>` blocks, never the transcript or source blocks already frozen. History is append-only and advances in whole 20-message steps so the cached prefix stays byte-stable between steps. Prefixes frozen before the marker still receive the rules in the tail.
- P2: chronicle entries are distilled facts with a verbatim quote; fields absent from host state may be distilled when the entry cites history. The archive request sends history once (cache-warm window plus older history).
- P3: stage snapshots reference scenery by id and list only characters present in the turn; images are stored once in the session. Name plates show roster display names; the speaker grammar adopts more of the reference's trades and non-name words.
- F1–F5: per-object writing blocks and readable Markdown profiles/places; existing `world/rules.md` gains a section; Writing handoff adds to the saved selection; discussion keeps recent rounds and offers 你来定; readiness reaches 75 when stage, lead, bond and tone are filled; locking keeps attribution; plan parsing gets one directed correction; unusable LINT reviews keep text instead of failing the pipeline.
