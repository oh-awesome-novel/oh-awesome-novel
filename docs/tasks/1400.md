## Goal

让长篇 Play 能说明窗口压力、主动进入下一阶段，并从当前世界线查回早期证据；整理不能丢失当前资源、知识边界或原始历史。

## Existing Baseline

[1360](1360.md) 已有 v4 五维归档、资源核验、最近两轮与新 session continuation；[1180](1180.md)/[1260](1260.md) 已有有界读模型和 source trace；[1190](1190.md) 已有 Rehearsal Scene Memory。`createCompactedPlaySession` 保留完整不可变图，只压缩模型可见历史。

代码入口：Core `play-compaction.ts`、`play-scene-memory.ts`、Play read model；Backend `handlePlayCompaction`；Desktop `PlayCompactionModal.vue`。

## Scope

- v4 Immersive Journey 的阶段目录、覆盖范围、来源身份、当前阶段与历史阶段定位。
- 使用真实配置预算/输出预留给出整理提醒；未知预算明确标注，不虚构阈值。
- 作者显式生成预览并确认开启新阶段；保存当前状态、资源、到期事件及至少两轮完整原文。
- 在作者选择阶段内做确定性只读检索；宿主一次性构造有界固定内存窗口，模型只在这份投影中搜索/读取。
- 命中带 session/selected-head、turn/message、quote/hash、当时状态与 visibility；扩大检索范围需新请求。
- 阶段目录可从现有 session/compaction metadata 重建；缺失/损坏来源只报告缺口。

## Constraints

- 不自动后台调用模型、强制归档、删历史或覆盖当前 session；失败/取消/漂移保持原分支不变。
- 首版不把 v4 archive 套到 v5；v5 保留已有 Scene Memory/windowing 并明确能力边界。
- 不建立自由可写 `/memory` 事实库，不暴露内部主机路径，不访问兄弟分支。
- 历史资源/知识只能作为当时证据，不能自动成为当前状态；Player 不能从命中或摘要间接得知 hidden 信息。
- protected 内容放不下时明确报告；不按字符硬截断，不为缓存稳定性放宽 capability。

## Done Criteria

- 50/200/1000 回合、至少两条分支的合成 fixture 覆盖预算、阶段切换、历史查回与重新打开。
- 归档后当前事实/资源/事件/知识不变，原文仍可回看；后续两轮使用 continuation 且不重复发送整段历史。
- Restore/Retry、source drift、过期预览、并发整理/生成与取消均不能混合分支或产生半提交。
- 历史检索有输出/候选字节上限和 omitted 说明；quote/hash/范围可验证，Player/Director 隔离有反例。
- 默认 SDK/Backend/Client/Desktop 的“提醒 → 审阅 → 继续 → 查回证据”旅程通过；文学摘要质量单独记录真实模型验收。

## Implementation Notes

v4 的阶段目录从当前选中图与归档来源链重建，逐段核验来源会话、分支前缀与原文哈希。缺失或损坏的来源显示缺口。预算使用当前模型配置的窗口减去输出预留，并显示受保护内容估算及可用的上轮请求证据。85% 是提醒策略，配置不完整时显示未知。v5 继续使用 Scene Memory。

作者先生成预览，再确认开启独立会话。预览绑定来源修订、选中头、来源指纹及最近两轮原文，确认接口核对所审阅的预览。检索以阶段和轮次为界，候选窗口上限为 256 KiB，最多返回 20 条、合计 24 KiB 的证据项，包含原文 UTF-16 范围、SHA-256、可见性与当时状态。作者可显式让模型从这份固定窗口选择证据，最多一次调用。

50、200、1000 轮双分支 fixture 覆盖预算、归档、重开、缺口和 Player/Director 隔离。受控 provider 通过默认 SDK 与本地 HTTP/SSE 驱动 Desktop 完成提醒、审阅、连续两轮续写、重启与历史查回。归档取消、来源漂移、并发生成与过期预览由独立回归覆盖。

真实模型的文学摘要质量仍待作者验收，可用同一存档核查人物关系、资源消耗、未结线索和最近两轮原文。
