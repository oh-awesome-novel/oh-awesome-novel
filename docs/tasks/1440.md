## Goal

修改旧章或设定后，给作者一份有依据的影响清单：哪些派生记录确定失效，哪些生成曾读过该来源，哪些章节只是可能相关，以及下一步可以显式复核什么。

## Existing Baseline

[1290](1290.md)/[0700](0700.md) 已有来源 hash、章/卷/全书摘要递归 freshness；[1030](1030.md) 结算记录来源证据；[1110](1110.md) 记录实际上下文来源；Project Health 已显示未整理/过期记录。

复用 Core `chapter-evidence-freshness.ts`、`summary-evidence.ts`、`project-health.ts`、对象引用与 usage/session evidence，以及 Git 的已有只读比较能力。

## Scope

- 从本次 accepted change，或作者显式选择的 Git/工作区前后版本发起只读影响分析。
- 分别展示确定的派生依赖、曾被生成读取的来源、词项/名称匹配的可能相关；每项给具体原因和证据范围。
- 旧章正文变更复用现有 freshness evaluator；设定变更用已登记引用/实际来源证据定位候选，不伪造完整剧情依赖图。
- 报告绑定比较双方内容 hash 与证据清单，支持重新打开和源变化后的 stale 提示。
- 提供打开文件、重新审稿、整理指定章节/卷/全书摘要等显式动作，复用既有 workflow。
- 索引/报告可重建，日志已清理或证据缺失时显示覆盖不足。

## Constraints

- 不以 mtime 判断剧情变化；“模型读过”不等于“剧情一定受影响”，名称命中更不能当确定依赖。
- 不自动撤销已接受的全局 state/timeline/foreshadow，不批量重写后续正文。
- 分析默认不调用模型；后续修复分别生成 PendingAction，不连锁自动生成或 Accept。
- 不引入图数据库、向量记忆或新的版本权威；历史仍由文件树/Git 与已记录证据解释。
- 未覆盖的文件不能显示为“确认不受影响”。

## Done Criteria

- 外部编辑与 PendingAction Accept 两种入口能对相同内容变化给出一致的确定性依赖结果。
- 正文变化可追溯到章/卷/全书摘要；同内容 touch 不产生虚假剧情影响。
- 场景 fixture 区分显式引用、实际上下文读取、同名但无关系、缺失证据和完全不相关文件。
- 报告过期、Git 不可用、历史记录被清理、重启和大规模文件清单均有有界/降级测试。
- 影响分析保持 canonical 零写入；作者选择修复后才进入对应现有 workflow 与审批。
- Desktop 可完成“查看变更 → 按依据分组 → 打开/复核 → 显式修复”，不把一般警告变成写作硬阻断。

## Implementation Notes

- Core 复用章级 freshness 和卷/全书递归 evaluator，分组展示正式派生依赖、已登记引用、生成读取和弱名称命中；缺少旧正文时保留 baseline hash，隐藏不可还原的变更前状态。不会自动撤回已接受的全局事实。
- Tools 提供 accepted action 与显式 Git commit → 当前工作区比较，按内容 hash 冻结，不解析 diff 或使用 mtime 判断变化。Git 版本固定为 commit，UTF-8/BOM 保留原始字节语义；扫描最多 1000 文件、8 MiB、10000 目录项，单次最多 16 个变更目标，报告最多 300 条结果。
- 从已记录 request 的 selected/compressed 可见来源、审稿报告和 Play 转章节候选读取依据，记录具体字段/请求位置与 hash；缺失、清理、截断和未记录输出目标均明确说明，不推断完整剧情依赖图。
- 可重建报告保存在 `.workspace/revision-impacts`；重开及修复跳转前重验双方版本、对象树清单、证据 fingerprint。Git/日志不可用显示覆盖不足，旧报告不转化为自动修复。
- Desktop Git 列表、已接受修改和右栏“影响”提供入口；按依据分组，打开文件/审稿，或向现有 Copilot 预填指定章/卷/全书整理指令。作者继续提交后仍走原有 PendingAction/Diff/Accept。
- 根目录 Core/Tools/Backend/Client/Desktop 回归覆盖同内容 touch、外部编辑与 Accept 的等价结果、递归摘要、引用/同名/无关文件、实际读取与省略来源、证据清理、Git 不可用、重启、stale、迟到响应和大树有界扫描；canonical manifest 在分析前后保持一致。
- 验证：build、lint、typecheck、docs:check、docs:build 通过；七个 workspace 全量覆盖 2192 项。首次全量中两处新 Tools 夹具的来源键/换行规则不匹配已修正，相关 5 项 Tools 用例复跑全部通过；其余全量用例通过。
