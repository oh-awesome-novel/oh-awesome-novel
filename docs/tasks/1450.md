# 1450 Guided Retry And Extra Action Suggestions

## Related Plans

## Goal

重演一回合时，作者可以说明“这次希望有什么不同”，行动本身不变；建议行动不够用时，可以再要一批。

## Existing Baseline

[1120](1120.md) 的原子 Retry 只接受 `baseRevision`，行动文本与类型从原 `worldSettlement` artifact 读取，结果是同一父节点下的 sibling。[1350](1350.md) 的插话是“取消后合并补充文本重发”，不适用于已提交回合。会话内只读提问通道已由 [1360](1360.md) 提供。

代码入口：Core `play-turn-retry.ts`、`play-turn-artifact.ts`；Backend `play-context-question.ts` 与 Retry SSE 路由；Desktop `PlayHistoryControls.vue`、`PlayComposer.vue`。

## Scope

- Retry 请求增加可选的重演指引，上限 500 字。行动文本和类型仍由宿主从原 artifact 读取，调用方不能覆盖。
- 指引只进入本次重演的消息尾部，不进入冻结前缀，不延续到后续回合。
- 指引写入新 sibling artifact 的可选作者视角字段（规划中的方案 B），使分支可自解释。旧 artifact 没有该字段时读取结果不变。
- “再给几个行动建议”：一次只读调用，结果只在界面临时显示，点击后填入输入框。不写会话快照，不推进 revision。
- 场景试演沿用已有的 Modify / 插话，不在本任务范围。

## Constraints

- 实施前先在 [PLAY_MODE_SPEC](../PLAY_MODE_SPEC.md) 写明 artifact 新字段的合同与旧数据兼容规则；不得为此放宽 v4 严格读取。
- 指引是 Director 信息：Player 视角的存档点摘要、世界线预览与采纳表单不得显示。
- 旧回合、其后代、事件、观察与采纳记录全部保留；取消、provider 或 schema 失败、revision 漂移保持零写入。
- 补充建议每次点击最多一次模型调用，失败不影响会话。

## Done Criteria

- 首回合、祖先节点、带到期计划事件的回合都能带指引重演，并产生正确的 sibling。
- 指引不出现在下一回合的模型请求中；不带指引的重演行为与现在逐字段一致。
- Player 视角看不到指引，有反例测试。
- 补充建议不改变 revision、建议列表快照与选中分支；生成中或其他操作占用时入口禁用。
- 默认 SDK → HTTP/SSE → Desktop 的“带要求重演”旅程通过。

## Implementation Notes

2026-11-10 交付，指引存放采用方案 B。合同写在 [PLAY_MODE_SPEC](../PLAY_MODE_SPEC.md) 的“带指引的重演”与“补充行动建议”两节。

- Core：`play-turn-artifact.ts` 增加可选 `retryGuidance: { sourceArtifactId, text }`，只允许出现在 v2 `worldSettlement` 上，严格校验（去空白后非空、≤500 字符、引用 ledger 中更早的同父 sibling）；旧 artifact 读取不变，不提升 schema 版本。`play-turn-retry.ts` 接受可选 `guidance`，错误码 `invalidGuidance`；指引只写到新 sibling。`play-turn-prompt.ts` 的 `<本次重演要求>` 块只进入这一次 Retry 的消息尾部。存档点摘要带可选 `retryGuidance`。`play-extra-suggestions.ts` 提供补充建议的只读指令与解析。
- Backend：Retry SSE 路由接受 `guidance`；新增 `POST /api/workspace/play-sessions/:id/suggestions`，复用 `askInPlayContext`（扩展为支持初始世界），每次点击最多一次模型调用，不写入；请求不占会话锁，生成后 revision 或 head 变化返回 409。
- Client：Retry 输入、`requestPlayExtraSuggestions`、存档点与 turn artifact 解析支持新字段。
- Desktop：世界线的重演确认框增加“这次希望有什么不同（可选）”，超长时字段提示并禁用确认；导演视角在存档点下显示“重演要求（导演视角）”，参与者视角不渲染。存在重演要求时导演视角开关可用。输入区提供“生成候选项 / 换一批”（与 [1520](1520.md) 共用），结果临时显示并标注，不保存。

验证：
- Core 10 项（首回合、祖先节点、带到期计划事件、旧 artifact、篡改引用 fail closed、不带指引逐字段一致、指引不进入冻结前缀与下一回合、零写入）。
- Backend 6 项 HTTP/SSE（指引只出现在 Retry 请求、下一回合不含、非法输入在调用模型前 400、schema 失败零写入、补充建议不改 revision / 快照 / 选中分支、初始世界、过期 head 409、坏回复只调用一次）。
- Desktop：世界线组件指引与 500 字上限、参与者视角反例；工作区 Retry 透传指引；“生成候选项 / 换一批”与失败不影响会话；默认 SDK（MockLanguageModel）→ HTTP/SSE → Desktop 旅程 `play-guided-retry-sdk-journey.test.ts`：Desktop 提交回合、带要求重演、导演 / 参与者视角、补充建议、下一回合不含指引。
- 在浏览器里用示例小说副本和受控演示模型走过同一流程。

实施中修复：客户端 turn artifact 严格解析原本会拒绝带 `retryGuidance` 的提交事件（真实应用里重演“结果未知”），已补字段与校验。
