## Goal

用旧会话的开局设置再开一局；在长局里看清人物关系是在哪一回合、因为什么变化的。

## Existing Baseline

[1140](1140.md) 的 Launch Package 冻结了来源、入场点、身份与参与者，但没有从已有会话预填向导的入口。[1120](1120.md) 已有 `relationshipChanged` 事件与 `relationship` 类 Pressure，变化散落在事件流中。

代码入口：Core `play-launch.ts`、`play-launch-session.ts`、`play-session-read-model.ts`；Desktop `components/play/launch/`、`PlaySessionRail.vue`、`PlayWorldHud.vue`。

## Scope

### 开局复用

- 会话列表与详情提供“以此开局再开一局”，用该会话冻结的 Launch Package 或快速开局表单预填向导。
- 预填后按当前文件重新校验来源；内容变化或缺失的来源在创建前标出，由作者决定沿用新内容或移除。
- 确认后创建全新会话，与旧会话没有分支关系。

### 关系与态度面板

- 从当前选中分支的 `relationshipChanged` 事件与 `relationship` 类 Pressure 派生只读面板。
- 按人物对列出变化的先后，每条链接到事件卡片与回合。

## Constraints

- 不做开局模板库，不新增具名开局的存储。
- 关系面板是可重建投影：不新增事实文件，不引入好感度数值。
- 面板只读当前选中路径；Player 视角按现有可见性规则过滤隐藏事件与原因。
- 复用开局不得把旧会话的 Play-local state、事件或认知带入新会话。

## Done Criteria

- 预填后不经修改即可创建；来源缺失或变更时在创建前给出诊断。
- 新旧会话互不影响，旧会话 revision 不变。
- 切换分支后关系面板只反映当前选中路径；有隐藏事件不泄漏的反例测试。
- 两项功能各有 Desktop 旅程测试。
