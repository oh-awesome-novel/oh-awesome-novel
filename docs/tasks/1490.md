## Goal

选择世界线上的两个节点，并排看到它们从哪里分开、分开之后各自变成什么样，帮助作者决定哪条线值得写成正文。

## Existing Baseline

[1120](1120.md) / [1160](1160.md) 已有命名存档点、Restore、Retry 与统一世界线，每个 v2 artifact 带完整分支快照。当前只能切换分支，没有差异视图。

代码入口：Core `play-turn-graph.ts`、`play-session-facts.ts`、`play-session-read-model.ts`；Desktop `PlayHistoryControls.vue`、`PlayWorldlineNode.vue`。

## Scope

- 在世界线视图选择两个节点，宿主找到共同祖先。
- 比较维度：回合数与作者行动列表、世界时钟、Play-local state 的不同叶路径、只在一边发生的事件、计划事件状态、认知与揭示；会话启用了 [1480](1480.md) 时增加原作走向。
- 面板出口：切换到某一边、给某一边命名存档点、对某一边生成结果报告。
- 无法可靠比较时给出明确说明。

## Constraints

- 比较由宿主从两条路径的快照确定性计算，不调用模型，不写任何文件，不改变选中分支与 revision。
- Player 视角按可见性过滤，隐藏事件、原因与认知不得因差异而泄漏。
- 比较结果是有界读模型：长路径需分页或折叠，不一次性加载全部回合正文。
- “用一段话总结两条线的区别”不在首版范围。

## Done Criteria

- 首回合就分开的两条线、祖孙关系的两个节点、跨越旧版 artifact 的路径都有正确结果或明确的“无法比较”说明。
- 比较前后会话文件逐字节不变。
- Player / Director 隔离有反例测试；1000 回合合成 fixture 下比较仍有界。
- Desktop 旅程“选两个节点 → 查看差异 → 切换到其中一边”通过。

## Dependencies And Sources

- 复用 1120、1160、1260；可独立于 1480 交付，1480 完成后补上原作走向维度。

## Implementation Notes

2026-11-12 已交付。`play-worldline-compare.ts` 从已验证的 artifact 图确定共同祖先与两端快照，比较行动、状态叶路径、独有事件、计划事件、认知/揭示、原作节点。先按视角过滤再计数；不调用模型、Restore 或持久化。旧节点缺少快照时给出明确原因。每组每页 40 条、文本 640 字符，1000 回合 fixture 不返回整段回合正文；宿主读取仍复用现有完整 session 校验，未宣称全历史读取成本为常数。

GET `/api/workspace/play-sessions/:id/worldline-comparison` 与 Client 严格 DTO 已接通。Desktop 世界线下方可选两个节点，显示共同起点、时钟与并排差异，并复用切换、命名和结果报告操作。切换视角、会话、workspace、revision 或开始修改时立即丢弃比较结果，取消和迟到响应不会重新显示旧视角内容。

新增 15 项回归：Core 7（首回合分叉、祖孙/同节点、旧快照、隐藏事件/状态/计划/揭示、原作、1000 回合分页），Backend 1（HTTP 与重启、完整 session 文件 SHA-256 不变），Client 3（查询绑定、字段/长度/分页校验），Desktop 4（选择/分页/操作、失效响应、真实 HTTP → Desktop → 切换/命名）。功能没有模型质量验收项。

验证环境为 macOS / Node 24.22.1。build、lint、typecheck、docs:check（78 tasks）与 docs:build 通过；七个测试 workspace 共 282 文件 / 2,133 项通过。首次全量运行中新增 Desktop 旅程的 1 秒等待短于读锁重试窗口，改为 5 秒后重跑整个 Desktop 套件（85 文件 / 422 项）通过。其余六个已通过的套件未重复运行；未执行原生 Electron 打包。

同日后续全量回归进一步复现后台刷新使 disabled 短暂切换、从而取消有效比较读取的竞争。现仅在 workspace/session/revision/lens、当前分支或节点选择变化时取消；后台刷新期间隐藏结果并禁用操作，结束后恢复同版本结果；存档点列表和会话详情的当前节点未同步前禁用比较。新增该竞争的独立回归，并重跑世界线 UI/HTTP 旅程。
