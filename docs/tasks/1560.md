## Goal

把两三部参考作品的写法并排看，并挑出这一次写作要借用的条目。

## Existing Baseline

每份已发布 reference 有按类别蒸馏的技法文件（文风、节奏、钩子、场景技法、人物技法、不可照搬）。[1080](1080.md) 的参考上下文选择器一次面向单份 reference 的条目。没有跨 reference 的并排视图。

代码入口：Core `reference-deconstruction-distill.ts`、`reference-work.ts`；Desktop 参考作品页面与参考上下文选择器。

## Scope

- 选择两到三份已发布且启用的 reference，按蒸馏类别并排显示条目。
- 勾选条目加入本次写作的参考选择，复用现有选择器及其预算提示。
- 某份 reference 缺少某个类别或材料已过期时明确标出。

## Constraints

- 只读，不调用模型，不写任何文件，不生成综合文风。
- 遵守每份 reference 的 `allowedUsage` 与启用状态；“不可照搬”条目只作提醒，不能被选为写作参考。
- 不引入持久的文风档案或新的事实域。

## Done Criteria

- 三份合成 reference 并排显示，类别缺失与过期有明确标记。
- 勾选的条目出现在随后写作请求的上下文追踪中，未勾选的不出现。
- 停用的 reference 不可选；切换工作区或 reference 不串用选择。
- 打开与浏览对照视图期间模型零调用。
