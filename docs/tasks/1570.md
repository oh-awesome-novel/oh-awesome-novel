## Goal

EPUB、DOCX 和带文本层的 PDF 可以直接导入为参考作品，不需要作者先手工转成 TXT。

## Existing Baseline

参考作品导入以 UTF-8 文本读取来源文件或粘贴内容，保留原始文件并记录校验值与结构指纹（[0900](0900.md)）。没有格式转换。

代码入口：Core `reference-work.ts`（`ReferenceImportInput`、来源清单）；Backend 参考作品导入接口；Desktop 导入对话框。

## Scope

- 导入前的本地格式转换：第一步 EPUB、DOCX；第二步带文本层的 PDF（可单独推迟）。
- 转换输出纯文本与章节边界提示，随后进入现有导入与结构识别。
- 保留原始文件与校验值；来源清单记录转换器标识与版本。
- 无法转换时给出具体原因：加密、扫描件无文本层、文件损坏、超出上限。

## Constraints

- 不联网、不做 OCR、不处理 DRM；不执行文档内脚本或宏，不解析外部引用。
- 解压体积、条目数与单文件大小有上限，超限即拒绝。
- 同一文件、同一转换器版本得到相同文本；转换器升级不静默改变已导入作品。
- 新依赖固定版本、随桌面包分发，许可信息进入现有 notices；依赖选择在实施计划中确定。
- 不保留图片、脚注与排版；不扩展导出格式。
- 转换只发生在导入这一显式动作内，模型不接触原始文件。

## Done Criteria

- EPUB、DOCX 样本导入后章节数与文本和预期一致，可进入现有拆解流程。
- 重复导入同一文件得到相同校验值与文本。
- 加密文件、扫描版 PDF、压缩炸弹样本与损坏文件各有明确的拒绝信息与回归。
- 打包后的桌面应用可完成一次 EPUB 导入。
- 现有 TXT / Markdown 导入有回归证明无变化。
