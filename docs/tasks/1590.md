## Goal

舞台模式的阅读手感接近常见 GalGame：自动播放、快进、隐藏界面、按句回看、可调字速，作者自己的行动也出现在舞台上。

## Existing Baseline

`VisualNovelTextBox` 以固定 24ms/字打字，第一击补全、第二击下一句；`VisualNovelStage` 的历史抽屉按回合列出原始正文；`speaker === 'user'` 的回合被过滤；名字牌颜色由文本哈希派生；名册没有颜色字段；场景氛围只按 `sceneId` 关键词切 CSS 色调，无转场。

代码入口：Desktop `components/play/VisualNovelStage.vue`、`VisualNovelTextBox.vue`、`VisualNovelChoiceOverlay.vue`。

## Scope

- 窗口全屏进入 / 退出（`Esc` 退出）。
- 推进：点击、空格、回车两段式推进；打字中连点补全并放行下一句，不吞输入；滚轮下翻下一句，上翻打开回看。
- 快捷菜单：Auto（按句长等待后自动推进）、Skip（快进到本回合末或选项处）、Log、隐藏 UI（右键或 `H`）、设置。
- 设置：字速、自动间隔、对话框不透明度、关闭打字效果；存应用界面偏好。
- 按句回看：按回合分组列出名字牌 + 句子；点击某句只读跳回该回合该句；分页沿用 `loadEarlier`。
- 作者行动上舞台：名册中 `isPlayer: true` 的角色用其名字牌，否则显示“你”；不显示立绘。
- 说话者立绘高亮并轻微前移，其余变暗；名字牌颜色沿用现有哈希色，名册带有 [1600](1600.md) 提供的 `looks.nameColor` 时优先使用。
- 场景 / 背景变化淡入淡出，立绘入场离场淡入；`prefers-reduced-motion` 下全部关闭且无打字效果。

## Constraints

- 只改 Desktop UI；不改 Play 协议、会话存储与名册格式，模型零调用。
- Auto / Skip 遇到选项、草稿结束或回合边界时停下，不代替作者选择或提交。
- 偏好不写入小说工作区。

## Done Criteria

- Auto、Skip、隐藏 UI、按句回看、字速设置在 Desktop UI 测试中可操作；键盘可完成全部操作。
- 连点测试证明打字中第二击直接进入下一句。
- 作者行动出现在舞台与回看中；只读回放不出现输入入口。
- Auto / Skip 不会越过选项或触发提交。
- reduced motion 下无动画、无打字效果。
- 没有 `nameColor` 的名册显示与现在一致。

## Implementation Notes

2026-11-12 交付，只改 Desktop UI。

- **快捷菜单**（舞台右上）：自动（`A`）、快进（`S`）、回看（`L`）、隐藏（`H` 或右键）、全屏（`F`）、设置。`Esc` 依次关闭设置、关闭回看、退出只读回看；全屏由浏览器 / Electron 的 Fullscreen API 处理，`Esc` 退出。
- **推进**：第一击补全、第二击下一句，换句后从第一个字重新打字。滚轮下翻前进一句，上翻打开回看；面板、输入框和行动栏里的滚轮不拦截，一串连续的滚轮事件只算一次。
- **自动**：句子显示完后等待“自动间隔 + 每字 45ms”再前进，到回合最后一句停住并保持开启，下一回合的草稿出现后继续；回看、设置打开或界面隐藏时暂停。**快进**是一次性动作：跳到当前已有的最后一句并显示全文。两者都不会选选项或提交行动。
- **隐藏界面**：只留背景与立绘；下一次点击或按键只用来恢复界面，不会同时触发选项或推进。
- **按句回看**（`VisualNovelLog.vue`）：按回合分组列出名字牌与句子，当前句高亮；点击某句只读回看该回合，不出现选项。只列已提交的回合，开场场景和进行中的草稿不在其中。
- **作者行动上舞台**：每个回合的第一句是作者的行动，取紧邻该回合之前的 `user` 消息；进行中的回合在裁判出字之前就先显示行动。名字牌用名册里 `isPlayer: true` 的角色名，否则“你”；不加立绘，也不高亮任何立绘。
- **草稿转正**：草稿提交成正式回合时保留阅读位置，不再从头重播。停止或失败的回合会从舞台撤下（此前失败的草稿会一直占着舞台、选项不出现），行动回到输入框。
- **高亮与过渡**：有人说话时其立绘前移并高亮、其余变暗；背景、场景名与立绘进出场淡入淡出。名字牌颜色优先用名册 `looks.nameColor`（`#RRGGBB`），没有或格式不对时沿用文本哈希色。
- **设置**（`VisualNovelSettings.vue`）：打字效果开关、字速 5–120 字/秒、自动间隔 0.3–5 秒、对话框不透明度 30–100%，存 `localStorage` 的 `oan:play:stage-reading`，所有工作区共用，读入时夹到合法范围。默认 40 字/秒，与原先的 24ms/字基本一致。
- **reduced motion**：不打字、关闭全部过渡与前移。
- 没有数据因本任务失效。
