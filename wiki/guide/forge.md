# 设定共创工坊

点击工作区顶栏的铅笔按钮 **设定共创工坊**，从一个角色、一处舞台或一个模糊想法开始。共创需要已配置的模型；草稿与正式设定分开保存，生成内容不会直接写入小说文件。

## 聊想法与锁定草图

1. 填写想法，点击 **开始新草稿**。
2. 阅读左侧的问题和台词样例。单选、多选或文风试写选项帮助你描述偏好，也可以补充自己的回答；拿不准时点 **你来定**，由向导挑一项并说明理由（该条目标为助手来源）。向导会参考此前几轮的问答，不重复已经问过的问题。
3. 在右侧草图检查舞台、角色、关系、文风和开场等条目。模型推测与转述标为助手来源。初始想法、你手动编辑保存的内容，以及与本轮输入或已选选项完整原文一致的条目标为作者来源；系统核验实际选项，不采信模型自报的来源标签。未锁定的作者条目只有在你提供新的完整原文表达并被准确引用时才会更新，模型自行推断的矛盾内容不会覆盖它。
4. 对已经确定的条目启用锁定并保存。后续商讨不能改写锁定内容；要调整时由你编辑或解锁。锁定不改变来源标签：锁定助手提议仍标为助手来源，只有你改写了内容才标为作者来源。

就绪度由系统根据草图计算：舞台、核心角色、你们的关系、基调四项都有内容时达到 75%，其余项目补足剩下的 25%。它不是文学质量评分，也不采信模型自报的数值；无需等到 100% 才能点击 **生成方案**。方案未通过校验时（例如三面性台词里混入解释），系统会带着错误原因自动重试一次。

## 定方案与分块撰写

方案包含角色的性格底色、具体行为、常态/压力/私密三面性、台词语料和反刻板解释，以及世界规则、地点、历史与开场白。还会要求具体目标、阻力、选择代价；涉及有限资源时应写清初态、消耗与兑现条件。

展开方案字段直接编辑；列表可拖动或使用上下移动按钮调整顺序。保存修改后，点击 **核准方案并分块撰写**。系统按世界、地点、角色、三面性、反刻板解释、开场白六块生成；地点、角色、三面性和反刻板解释按每个地点或角色分别成块。每块都会扫描套话并尝试一次局部修正；修正结果不可用时保留原文，结果中会标出仍待你判断的套话提示数。

生成块可以展开阅读。模型可能不给某个提示提供替换，扫描也不能判断所有文学问题。请自行检查事实、人物声音和开场是否有吸引力。

## 审查并入库

点击 **定稿生成并入库：审查差异**，打开共享审批面板。此时正式文件仍未改变。

候选通常包括角色的 `meta.yaml`、`profile.md`、`summary.md`、`roster-profile.yaml`，以及地点、世界规则和开场白文件。每个角色的 `profile.md` 是可读的 Markdown，只包含该角色自己的档案、三面性和特质边界；每个地点文件也只包含该地点。已有角色或地点 ID 冲突时需修改方案 ID；已有 `world/rules.md` 时只在末尾追加以方案标题命名的一节，原有规则保留不动。

- **Accept**：接受这项审批中的全部文件。默认随后尝试 Git 提交；关闭自动提交时保留已接受的工作区修改。
- **Reject**：不改正式设定。返回草稿重新修改、生成即可。
- 文件、仓库或草稿版本变化导致审批失效时，重新载入并生成提案，不要重复接受过期差异。

详细规则见 [审阅与接受修改](review.md)。待审批项不能逐行接受；应在方案阶段先改好范围。

## 入库后开演或入书

重新打开工坊，选择草稿并点击 **刷新审批状态**。只有确认已接受且正式文件仍与获准版本一致，才可使用：

- **一键开演**：创建独立 Play 会话，带入角色、设定与开场白，并进入视觉小说视窗。后续推演仍是 Play-local 内容，不会自动改写设定。
- **一键入书**：切回 Writing，把已接受的角色/世界文件加入明确的设定引用选择，已选的其他来源会保留（总数上限 16 项，新设定优先）。发送前可移除单项；排队消息保留入队时选定的来源。引用不会自动修改当前章，也不会创建虚假的 Play 结果附件。

入书后的引用选择保存在当前项目 `.workspace/writing/selected-sources.json`，不会修改 `novel.config.yaml` 或章节正文。重开窗口或重启服务后会自动恢复，后续写作与审稿持续引用，直到你从引用面板移除；移除也会保存。切换项目不会沿用另一个项目的选择。正式文件后来被改动时，旧草稿的交接会拒绝使用旧版本，应先审查当前设定。

## 恢复草稿与限制

通过 **恢复草稿** 选择已保存草稿，或点击 **重新载入** 获取最新版本。草稿存于工作区 `.workspace/forge/drafts/`，正式设定仍存于普通对象文件目录。

旧版本工坊写成的、尚未提交审批的草稿，载入后会回到“定方案”阶段：方案保留，需要重新点击 **核准方案并分块撰写**，按每个角色和地点重新成块。已经提交审批的草稿不受影响。

一次生成失败不会推进草稿版本。若提案已准备好但审批建立中断，重新打开草稿后的 **恢复审批** 可继续使用原提案。

同一草稿一次只能由一个操作修改。正常并发冲突可在完成后重载；进程突然退出可能留下占用锁，单纯重载不能清除。此时可另建草稿继续工作，或由维护者确认旧进程已结束后恢复内部锁；不要删除整个 `.workspace` 或正式设定目录。

当前不会调用生图或语音服务。模型生成质量仍需要作者审阅，尚未验证真实模型下的文学质量或性能收益。
