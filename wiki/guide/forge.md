# 设定共创工坊

点击工作区顶栏的铅笔按钮 **设定共创工坊**，从一个角色、一处舞台或一个模糊想法开始。共创需要已配置的模型；草稿与正式设定分开保存，生成内容不会直接写入小说文件。

## 聊想法与锁定草图

1. 填写想法，点击 **开始新草稿**。
2. 阅读左侧的问题和台词样例。单选、多选或文风试写选项帮助你描述偏好，也可以补充自己的回答。
3. 在右侧草图检查舞台、角色、关系、文风和开场等条目。模型推测标为助手来源；你明确编辑并保存的条目标为作者来源。
4. 对已经确定的条目启用锁定并保存。后续商讨不能改写锁定内容；要调整时由你编辑或解锁。

就绪度反映草图已填项目的比例，不是文学质量评分。无需等到 100% 才能点击 **生成方案**。

## 定方案与分块撰写

方案包含角色的性格底色、具体行为、常态/压力/私密三面性、台词语料和反刻板解释，以及世界规则、地点、历史与开场白。还会要求具体目标、阻力、选择代价；涉及有限资源时应写清初态、消耗与兑现条件。

展开方案字段直接编辑；列表可拖动或使用上下移动按钮调整顺序。保存修改后，点击 **核准方案并分块撰写**。系统按世界、地点、角色、三面性、反刻板解释、开场白六块生成，并扫描套话、尝试局部修正。

生成块可以展开阅读。模型可能不给某个提示提供替换，扫描也不能判断所有文学问题。请自行检查事实、人物声音和开场是否有吸引力。

## 审查并入库

点击 **定稿生成并入库：审查差异**，打开共享审批面板。此时正式文件仍未改变。

候选通常包括角色的 `meta.yaml`、`profile.md`、`summary.md`、`roster-profile.yaml`，以及地点、世界规则和开场白文件。已有角色或地点 ID 冲突时需修改方案 ID；`world/rules.md` 的更新会显示完整差异，尤其要检查是否覆盖已有规则。

- **Accept**：接受这项审批中的全部文件。默认随后尝试 Git 提交；关闭自动提交时保留已接受的工作区修改。
- **Reject**：不改正式设定。返回草稿重新修改、生成即可。
- 文件、仓库或草稿版本变化导致审批失效时，重新载入并生成提案，不要重复接受过期差异。

详细规则见 [审阅与接受修改](review.md)。待审批项不能逐行接受；应在方案阶段先改好范围。

## 入库后开演或入书

重新打开工坊，选择草稿并点击 **刷新审批状态**。只有确认已接受且正式文件仍与获准版本一致，才可使用：

- **一键开演**：创建独立 Play 会话，带入角色、设定与开场白，并进入视觉小说视窗。后续推演仍是 Play-local 内容，不会自动改写设定。
- **一键入书**：切回 Writing，把已接受的角色/世界文件加入明确的设定引用选择。发送前可移除单项；排队消息保留入队时选定的来源。引用不会自动修改当前章，也不会创建虚假的 Play 结果附件。

入书后的选择属于当前写作窗口，不是修改 `novel.config.yaml`。窗口重开后可从已接受的 Forge 草稿再次入书。正式文件后来被改动时，旧草稿的交接会拒绝使用旧版本，应先审查当前设定。

## 恢复草稿与限制

通过 **恢复草稿** 选择已保存草稿，或点击 **重新载入** 获取最新版本。草稿存于工作区 `.workspace/forge/drafts/`，正式设定仍存于普通对象文件目录。

一次生成失败不会推进草稿版本。若提案已准备好但审批建立中断，重新打开草稿后的 **恢复审批** 可继续使用原提案。

同一草稿一次只能由一个操作修改。正常并发冲突可在完成后重载；进程突然退出可能留下占用锁，单纯重载不能清除。此时可另建草稿继续工作，或由维护者确认旧进程已结束后恢复内部锁；不要删除整个 `.workspace` 或正式设定目录。

当前不会调用生图或语音服务。模型生成质量仍需要作者审阅，尚未验证真实模型下的文学质量或性能收益。
