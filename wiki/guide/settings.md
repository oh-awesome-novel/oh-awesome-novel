# 模型与偏好设置

模型配置属于应用设置，可供多个小说工作区使用；Writing Profiles 属于当前作品，用来控制写作提醒和参考资料分析的输出范围。

## 添加模型提供方

返回启动器，点击左侧「模型」。该页可以管理多个 Provider（模型提供方）及每个提供方下的多个模型。

1. 点击「添加 DeepSeek」「添加 OpenAI」「添加 Ollama」等预设按钮，或选择「自定义 OpenAI-compatible」。
2. 检查 `Provider ID` 和「显示名称」。ID 用来区分配置，显示名称便于你辨认。
3. 云端模型填写 API Key；Ollama 使用本地服务，无需 API Key。
4. 自定义服务和 Ollama 还需要核对 `Base URL`。Ollama 的界面默认值为 `http://127.0.0.1:11434/v1`。
5. 在 `Model ID` 中填写服务端实际提供的模型名，点击「添加模型」；也可以尝试「获取模型」。
6. 点击模型行左侧的圆点，设定该 Provider 的默认模型。
7. 按需勾选「保存后设为默认 provider」，点击「保存 Provider」。

界面提供 DeepSeek、OpenAI、OpenCode Go、Xiaomi MiMo、Ollama 和自定义兼容服务预设。预填的模型名称只是表单默认值，请使用你的服务实际支持且有权限访问的模型。

## 检测连接和切换默认模型

点击「检测模型」，或某一模型行里的「检测」。检测会实际请求所选服务，可能产生该服务的调用用量。看到成功结果后，再回到工作区开始写作。

「获取模型」失败并不一定表示模型不可用：部分兼容服务不提供模型列表。你可以手动添加已知 `Model ID` 后进行检测。

切换现有配置时：

1. 在 Provider 列表点击「编辑」。
2. 选择需要的默认模型并「保存 Provider」。
3. 需要同时切换提供方时，点击该 Provider 的「设为默认」。

Copilot 使用当前默认 Provider 和默认模型。工作区里的「模型切换」或顶部模型图标会打开快捷配置窗口；完整的多 Provider 管理在启动器「模型」页。

编辑已有 Provider 时，API Key 留空会保留之前保存的值。界面不会重新显示原来的完整密钥。

## 模型上下文容量与用量

获取模型列表时，如果服务返回了上下文容量，模型行会显示 `Context` 和对应数值。它是模型配置中的容量信息，不是本轮已经使用的 token，也不是账户剩余额度。

本轮估算与模型返回用量在工作台 Copilot 的「上下文与用量」中查看。该面板是只读统计，不会修改模型设置或小说文件；详见[上下文与用量](usage.md)。

模型输入预算需要结合已知上下文容量和输出预留。仅看到 `Context` 并不保证当前已有完整预算，面板仍可能显示「模型上下文预算未知」。未知时会继续估算，不会把缺少配置当作无限容量。

当前模型表单没有可直接编辑 `contextWindow`、`maxOutputTokens` 或输入预算的控件，也没有价格或费用预算设置。遇到上下文超限时，可以先缩小本轮任务、减少附带参考或开启新对话；需要更大容量时，选择服务实际支持的合适模型并保存为默认。

统计中的 `Estimated` 不能用于精确计费；`Actual unavailable` 表示服务未提供可用统计，不代表此次请求没有费用。

## 先不配置模型

打开工作区遇到「配置 LLM Provider」窗口时，可以点击「稍后配置」。文件树、章节和已有内容仍可浏览，Copilot 会显示「当前不可用」。之后点击「配置 Provider」补齐即可。

Ollama 也需要真实运行的服务和已安装模型；只保存一个本地地址并不会自动启动 Ollama 或下载模型。

## 写作配置（Writing Profiles）

在工作区顶部点击 `Writing Profiles`，或打开右侧 `Profiles` 页签。该页管理两个方面：

- **拆书输出**：抽象技法、世界观、角色、关系、大纲和时间线。
- **Writing 提醒**：独立表达、AI 味审查、角色一致性和改编自由。

内置配置包括「商业写作」和「同人二创写作」，标有「内置只读」。点击「设为当前」切换；中央 Copilot 顶部可以查看当前配置摘要。切换从下一次请求生效，不会改写已经生成的回复或待审批项。

需要自己的组合时：

1. 点击「新建」，或在现有配置上点击「克隆」。
2. 填写安全 ID、显示名和说明。ID 以字母开头，只包含字母、数字和连字符，最长 64 个字符。
3. 新建或编辑时至少选择一种拆书输出，并勾选所需的 Writing 提醒。
4. 保存后点击「设为当前」。

克隆会完整复制原有输出和提醒，创建副本后可继续编辑。内置配置不能直接修改或删除；删除自定义配置时需要再次点击「确认删除」，且不能删除当前正在使用的配置，先切换到其他配置即可。

这些选项是创作提示和分析范围，不会自动让内容符合你的要求，也不会替你接受文件修改。参考资料的具体流程见 [参考资料](references.md)。

## 主题与发送快捷键

返回启动器，点击左下角齿轮进入「设置」。

「外观」可以切换浅色或深色主题；工作区顶部也有主题按钮。

「快捷键 → 消息发送」可以选择：

| 选项 | 操作 |
| --- | --- |
| Enter | Enter 发送，Shift + Enter 换行 |
| Cmd + Enter / Meta + Enter | 使用系统对应的 Meta 键加 Enter 发送 |
| Ctrl + Enter | Ctrl 加 Enter 发送 |

默认在 macOS 使用 Cmd + Enter，其他平台使用 Ctrl + Enter。输入框发送按钮旁也提供发送方式选项；以当前显示的快捷键为准。

## Git 自动提交

默认情况下，接受待审批项后会尝试自动提交该项的文件。左侧底部会显示「Git 自动提交」或「Git 手动提交」。

当前设置页没有对应开关。需要关闭时，由你在外部编辑器中打开工作区的 `.oan/config.yaml`，保留原有字段，在现有 `git` 配置中设置：

```yaml
git:
  autoCommitOnAccept: false
```

如果已有 `git:` 段，修改其中的字段，不要重复新增同名段。保存并重新进入工作区后确认状态。

关闭后，接受修改仍会写入小说文件，但不会自动提交或同步。需要保存历史时显式使用 Git 页的提交入口。详情见 [Git 与历史](git.md)。
